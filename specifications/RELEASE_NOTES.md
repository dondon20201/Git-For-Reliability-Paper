# Release notes for the specification documents

These files are copies of specification files from the development repository;
each was committed prior to the results it describes (see `../provenance/provenance.md` for dates).

Two modifications were made to these files prior to release:

1. Internal project management information was altered or removed: run numbers in
   titles and cross-references (e.g. "dispatch 037" to "E4"), labels "Dispatch B"
   and "Dispatch C" replaced by "Battery B" and "Battery C", working session
   labels, and formatting for project internal reports (use of dash and quote,
   content of internal text).
2. One sentence in `P2_spec.md` and two sentences in `P2_spec_erratum.md` were
   altered to be valid following change 1.

No decision rule, seed, sample definition, threshold, gate, estimand, or hypothesis
was changed. The earlier change from "pre-registration" to "pre-specification"
is detailed in `TERMINOLOGY_ERRATUM.md`.

Because of these changes, the copies here are not byte-identical to the
versions committed in the development repository. The analysis content is
identical.

File paths inside the documents refer to the layout of the development
repository. The table in `../ANALYSIS_MATERIALS.md` maps each specification to the step of
this repository that carries it out. At integration, historical freeze tag labels
were replaced with references to the same freeze points or commit IDs in five
places. The reported analysis sequence and thresholds were not changed.

The opening descriptions in `E1_contract.md`, `E2_spec.md`, `E3_spec.md`, and `E3b_spec.md`
were reworded after integration on 2026-10-23. Their analysis rules were unchanged.
